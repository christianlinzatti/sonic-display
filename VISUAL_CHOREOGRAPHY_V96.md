# V96 – Visual Choreography Timeline

- Drag-and-drop zum Umordnen der gespeicherten Dance Loops, mit Pfeiltasten als Alternative.
- Zeitproportionale Blöcke und grafische Slider für die Übergangsdauer.
- Gesamte Sequenz in der bestehenden 3D-Vorschau starten oder stoppen.
- Die 3D-Vorschau wechselt Clips an Loop-Grenzen; **Crossfades und Beat-Ausrichtung finden weiterhin nur in der Live-Bühne statt**.
- Vorschau wiederholt optional die Sequenz. Die Presets werden wie in V95 gespeichert; Original-GLBs bleiben unverändert.
- Vor produktivem Einsatz `npm install && npm run build` prüfen.
