# Sonic Display V76 — Lyrics Studio

In Settings → Anzeige → Lyrics · Animation: live preview, size, position, glow, two gradient colors, animation speed and lyrics offset (±5 seconds). Values persist in browser preferences; no extra service is necessary. All four existing styles are preserved.

Positive offset advances the displayed lyrics relative to Spotify playback. Word timing is estimated for line-synced lyrics. Preview uses demo lyrics and a manual timeline slider, not the current Spotify track.
