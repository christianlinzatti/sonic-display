# Sonic Display V73 — Kinetic Typography

- Default style: kinetic, intensity 65%, beat reaction on, word highlighting on.
- Settings → Anzeige → Lyrics · Animation: change style, intensity, beat response, word highlighting.
- Active line remains centered within a five-line sliding window; beat pulse reads the existing audio-analysis context.
- For line-synced lyrics, words are highlighted **approximately** by dividing each line’s time evenly among its words. This is *not* actual word-level timestamps.
- Unsynced lyrics do not claim word-level synchronization.
- Reduced-motion preference and OS reduced-motion setting suppress intense animations.
- V72 avatar/admin/blob functionality retained.
