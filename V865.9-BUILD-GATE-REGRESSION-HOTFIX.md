# V865.9 — Build-Gate-Regression-Hotfix

## Fehlerursache

`tests/v6661-automatic-genre-regression.cjs` erwartete mit `assert.equal(scripts.prebuild, 'npm run check:fast')` einen unveränderten V680-Build-Aufruf. In V865 führt `prebuild` zuerst V865–V851 aus und endet danach mit `npm run check:fast`. Diese neue Reihenfolge ist beabsichtigt.

## Korrektur

Sieben historische Tests wurden angepasst (V481, V482, V494, V536, V571, V666.1 und `release-type-isolation`). Neu ist ein gemeinsamer Test-Helfer `tests/helpers/prebuild-gate-v8659.cjs`:

- Prebuild darf neuere Versionstests enthalten, muss mit `check:fast` enden.
- Die erste getestete Release-Version muss mindestens V865 sein, alle Versionsprüfungen sind absteigend sortiert.
- Zusätzliche Prebuild-Kommandos müssen echte `test:v...`-, `:types`- oder `:ui-types`-Prüfungen sein; keine Build-Bypässe.
- `check:fast` und `check:release` behalten den vollständigen Produktiv-TypeScript-Check.
- Die V571-Prüfung kontrolliert jetzt den Ausschluss historischer Smoke-Suiten, statt eine veraltete Gesamtlänge von weniger als 60 Zeichen zu erwarten.
- Das neue `v8659-prebuild-gate-compat-regression.cjs` enthält sechs Negativfälle, die unwirksame oder umgangene Build-Gates ablehnen.

**Produktive Komponenten, `package.json`, Next.js-Konfiguration und die V865-History-Funktionen wurden nicht verändert.**

## Lokale Testergebnisse

Erfolgreich: V666.1 (24 Prüfungen, 12.000 Frames), V666 (48 Gruppen, 15.000 Frames), V666-Core-TypeScript, V481, V482, V494, V536, V571 (46 Gruppen), Release Type Isolation, V865, V865.9 Guard inkl. 6 Negativfällen, Syntax (1.261 TS/TSX), Architektur, V752-Lockfile-Integrität, Modul-Dateinamen (2.137 Dateien). Es wurden keine Tests deaktiviert.

Nicht erfolgreich ausführbar: gesamtes `npm run typecheck` wegen fehlender installierter React/Next.js/Node-Abhängigkeiten; `npm run build --ignore-scripts` endet mit `next: not found`. Kein Beleg für einen fertigen Produktionsbuild. Windows PowerShell Installer ist hier nicht unter Windows getestet.

## Installation (PowerShell)

ZIP **in ein separates Verzeichnis** entpacken. Von dort:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-V865.9.ps1 -ProjectPath "C:\Users\Christian\git\sonic-display"
```

Der Installer verifiziert SHA256, sichert vorhandene Dateien in `%TEMP%`, installiert die korrigierten Tests und führt acht Funktions-/Regressionstests aus.

Danach im Projekt:

```powershell
npm run test:v6661
npm run test:v666
npm run test:v666:types
npx tsc --noEmit
npm run build
```
