```bash
npm run test:v1113
npm run test:v1113:types
node scripts/v959-source-preflight.cjs
```

Unter Einstellungen → Bühne → 360° Arena → AI Show Designer den Bereich **V1113 AI Performance Director** öffnen, Stil und Ausdrucksstärke auswählen und **V1113 Bühnenperformance jetzt proben** wählen. Die Vorschau zeigt sieben Szenen mit Neon Pulse, Festival Nova und Chrome Beat und ändert bis zum separaten **Übernehmen** nichts am gespeicherten Plan. **Rückgängig** erhält den vorherigen Showplan, sofern er zwischenzeitlich nicht manuell verändert wurde.

Die Gestik-Angaben sind Regiehinweise; individuelle GLB-Animationsclips pro Künstler werden noch nicht in Echtzeit ausgelöst. Ausgeführt werden nur vorhandene gemeinsame Kamera-/Tanzmodi. Die vollständige Freigabe erfordert Ubuntu-Produktionsbuild mit Chromium Desktop/Touch sowie Windows-Build in GitHub Actions.
