# V455 – Beautiful Lyrics Experience

- Gemeinsamer, playback-basierter Lesbarkeitsplan für lange und schnelle Zeilen.
- Dynamische Dämpfung von Wortbewegungen bei Rap mit hoher Wortdichte; keine Phonem-Erkennung.
- Sanft reduzierte Schriftgröße für sehr lange Texte, ohne Nutzereinstellungen zu überschreiben.
- Zeilen-, Wort- und Reduced-Motion-Modi bleiben erhalten.
- Bestehende V382-Karaoke-Zeitbasis und alle anderen Visualisierungen werden nicht ersetzt.
- Prüfen: `npm run verify:v455`, danach `npm run typecheck` und `npm run build`.
