# V389.1 – Windows Build Hotfix

- Repariert fünf Dateinamenkollisionen: Hilfsmodule hatten unter Windows denselben Dateinamen wie ihre React-Komponenten, nur mit anderer Großschreibung. Die `.ts`-Hilfsmodule tragen jetzt eindeutige `*Helpers*`- bzw. `*State*`-Dateinamen; Imports in Komponenten und Tests wurden entsprechend angepasst.
- Der Client-Import aus `ably` wurde durch `ably/modular` mit `BaseRealtime`, `WebSocketTransport` und `FetchRequest` ersetzt. Token-Endpunkt und Channel-Subscription bleiben bestehen.
- Keine Änderung an den gespeicherten Nutzerpräferenzen oder bestehenden Shows.

## Prüfung auf Windows

```powershell
npm install
Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
npm run build
```

**Hinweis:** Die Syntax-/Offline-Tests ersetzen nicht den echten Next.js-Produktionsbuild mit installierten npm-Abhängigkeiten.
