# V865.3 - Regression Compatibility Hotfix (for V865)

This is a regression-test compatibility hotfix for Sonic Display V865. Package and lockfile versions stay at `0.1.0-v865`; runtime features are unchanged.

## Problem
Older regression tests pinned `package.json` to a short list or maximum release (V843 allowed only V843..V850). Further tests expected historical source strings and the old exact `prebuild` command. The project is now V865, so a passing feature can fail for unrelated version and refactoring reasons.

## Changes
- V843 checks that the release version is at least V843 and that package/lockfile agree. No upper version limit.
- 51 changed regression test files align obsolete version caps with the existing monotonic minimum-version helper. The file list in this ZIP is authoritative. Original feature and safety assertions remain except references updated for later real implementation, e.g. V249 avatar motion loader, V791 cinematic transition camera path, V792 camera V848, V797 spotlight V838 and V831 extended `prebuild` protections.
- The earlier V844--V848 `startsWith` => `includes` fixes are bundled again for users who skipped the previous installer.
- V865 itself checks gate presence (`includes`) for future V866+ instead of assuming it stays the first test forever.
- `verify:offline` now includes the maintained `test:music-themes`; V168 theme regression checks its modern genre registry.
- `tests/helpers/project-version-v651.cjs` is bundled and asserts a version format of `0.1.0-v<number>` plus a version lower bound. No tests are globally skipped.

## Verification in current environment
- 58/58 *selected affected and companion JavaScript regression tests* passed (see `V865.3-TEST-RESULTS.md`).
- V843 and V841/V842, V844--V850, V865 were explicitly re-run successfully.
- `npm run test:v843:types`, `npm run test:v865:types`: passed.
- `npm run check:syntax`: passed (1,261 source files).
- `npm run check:architecture`: passed.
- `npm run test:module-case`: passed.
- `npm run check:lockfile:v752`: passed.
- Full `npm run typecheck`, `npm run build`, production browser runtime and *entire* historic regression suite: NOT passed in this environment; complete node_modules / Next.js deps are absent. Run locally with npm ci and full build. Never treat this hotfix as production released on those tests alone.

## Installation
Use **Install-V865.3.ps1** from the smaller hotfix ZIP, with `-ProjectPath` set to your local Sonic Display source. The installer checks project version/lockfile, backs up every overwritten file into `.sonic-hotfix-backups`, verifies copied SHA256 values, and runs selected tests.

Example PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-V865.3.ps1 -ProjectPath "C:\Users\Christian\git\sonic-display"
```

After applying, from the project root:

```powershell
npm run test:v843
npm run test:v842
npm run test:v841
npm run test:v865
npm run typecheck
npm run build
```

If a different error occurs, include the **first failing test and its full assertion output**.
