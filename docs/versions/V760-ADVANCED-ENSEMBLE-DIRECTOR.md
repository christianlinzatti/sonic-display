# V760 – Advanced Ensemble Director

Basiert auf V759. Opt-in im Multi-Avatar Stage Studio (V326).

- Deterministische 4/8/16-Takt-Phrasen, Verse/Gegenakzente, Build/Bogen, Hook/Unison, Drop/Wings.
- Visuelle Führungsposition kann wechseln; **niemals** Gesangszuordnung.
- Verwendet bestehende V517/V495-Rollen; nur automatische 3–4er-Gruppen.
- Manuelle V326-Cues, V385/V416/V496-Gesang, vorhandene GLB-Animationen, Foot-IK und X-Lanes behalten Vorrang.
- Kleine additive Arm-/Kopf-/Schulterakzente über vorhandene V452-Overlays; die V506/V508-Sicherheitsregel wird danach angewandt.
- Maximal 1 cm zusätzliche Tiefenbewegung, nur bei bestätigter Fußfreigabe V494 und niedrigem Kollisionsrisiko.
- Deaktiviert bei Pause, Low-Tier, Reduced Motion, expliziten Künstler-/Manual-Settings.
- Vorschau im Editor ist eine **Simulation**, kein Nachweis einer korrekt gerenderten GLB-Show.
- Ohne vollständige npm-Abhängigkeiten und visuellen Browserlauf ist dies kein produktionsverifiziertes Release.
