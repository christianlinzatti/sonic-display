# Sonic Display V865.11 – Camera Pipeline + Historical Gate + Isolated GLTF Types

## Fehlerursache

- V429 suchte die finalen Lyrics-Schutz-Token `guardAutomaticCameraV351(naturalFramedV655`, obwohl die aktuelle V865-Kette nach V429 u. a. V497, V655, V682, V747, V792, V797, V806, V809 und V838/V848 verarbeitet. V351 schützt den finalen `framedV848`.
- V497 suchte analog den längst abgelösten Kamera-Endpunkt `concertFramedV497` und verlangte eine direkte, heute nicht mehr vorhandene `build:preflight`-Teilzeichenfolge.
- V439-Scan-Test hatte einen isolierten GLTFLoader-Stub, der `scene`, `scenes`, `loadAsync` und die privaten GPU-Entsorgungs-Typen nicht enthielt.
- V407 verlangte einen direkten Overlay-Aufruf auf V510, obwohl im produktiven Code inzwischen V746/V757 als nachfolgende, geschützte Verarbeitungsschritte existieren.

## Änderungen

1. `tests/v429-cinematic-rap-camera-regression.cjs`: realer V848-Guard und explizite Positionen sowie manueller Prioritätsguard geprüft.
2. `tests/v497-cinematic-concert-choreography-regression.cjs`: tatsächlicher V497→V848→V351 Ablauf; der V497-Test ist jetzt im historischen Gate verankert.

4. `tests/stubs/v439-glb-loader.d.ts`: realistische, ausschließlich testbezogene Three-/GLTF-Schnittstellen für private Asset-Entsorgung (kein produktives Typ-Override).
5. `tests/v407-rhythm-rap-performance-regression.cjs`: V510→V746→V757→V371-Reihenfolge mit expliziter `index >= 0`-Prüfung.

Produktive 3D-/Kamera-/Avatar-Komponenten wurden nicht verändert. Der Projektversionsstring bleibt `0.1.0-v865`.

## Verifikation

**Bestanden:** 23 ausgewählte Kamera-/Rap-/Konzert-Regressionen (V407, V429–V433, V439, V496–V497, V528, V540, V550, V633, V655, V682, V747, V792, V797, V806, V809, V838, V848, V865); isolierte TS-Tests V439 core+scan, V497 core; `npm run check:syntax` (1.261 TS/TSX), `check:architecture`, `test:module-case` (2.137 Dateien), `check:lockfile:v752`.

**Offen:** Vollständiger TypeScript-Check und produktiver Next.js-Build können in dieser Umgebung mangels `node_modules` nicht ausgeführt werden. Keine Windows-/PowerShell-Ausführung des Installers. Ein kompletter rekursiver Build-Preflight mit sämtlichen früheren Versionen wurde nicht ausgeführt. Für Produktionsfreigabe lokal `npx tsc --noEmit` und `npm run build` vollständig ausführen.

## Installation

ZIP in einen separaten Ordner entpacken, dort PowerShell starten:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-V865.11.ps1 -ProjectPath "C:\Users\Christian\git\sonic-display"
```

Der Installer erstellt eine Sicherung im TEMP-Verzeichnis, verifiziert die SHA256-Dateihashes und startet V429, V497, V496, V407, V439 und V497-Types. Im Fehlerfall werden die überschriebenen Dateien soweit möglich wiederhergestellt.
