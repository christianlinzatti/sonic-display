# V298 – Smart Camera Composer

Music-aware layer for live Three.js camera direction. Section-specific moves for break/build/hook/drop, with energy-sensitive gain and adjustable strength. Keeps authored keyframes as base camera pose; avatar bounds tracking is applied afterwards. Respects playback pause and reduced motion. Disabled by default. Settings under Dynamic Stage → Interactive Camera Director.

Run `npm run verify:offline` and, with dependencies installed, `npm run build`.
