# V865.12.1 – Windows PATH/Path Test-Hotfix

## Ursache

Unter Windows erzeugt `cleanPathEnv` korrekt `Path` anstelle von `PATH` (Umgebungsvariablen sind dort ohne Beachtung der Groß-/Kleinschreibung definiert). Der Regressionstest V865.12 las jedoch ausschließlich `env.PATH`, wodurch das erwartete Ergebnis auf Windows `undefined` war.

## Änderung

- Regressionstest verwendet den plattformrichtigen PATH-Schlüssel und Trennzeichen.
- Neue Plattformtests decken Windows `Path`, `PATH`, doppelte Pfade und Laufwerksbuchstaben ab.
- Runner erlaubt einen Test-Plattformparameter in `cleanPathEnv`, damit die Windows-Pfade auch auf Linux-CI getestet werden können. Laufzeitverhalten des Runners bleibt ansonsten unverändert.
- Alle ursprünglichen V865.12-Dateien werden mitgeliefert, da der fehlerhafte ursprüngliche Installer bei einem fehlgeschlagenen Test ein Rollback durchführt.
- Produktive Komponenten und historische Smoke-Prüfungen sind unverändert. Projektversion bleibt 0.1.0-v865.

## Installation

Entpacken und im entpackten Ordner ausführen:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-V865.12.1.ps1 -ProjectPath "C:\Users\Christian\git\sonic-display"
```

Der Installer erstellt Sicherungen, installiert das Paket, verifiziert SHA256 und führt zunächst `test:v86512:flat`, danach den flachen V649/V650-Probelauf aus. Bei Fehlern wird die vorherige Projektfassung wiederhergestellt.
