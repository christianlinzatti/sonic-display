# V259 – Smart Multi-Avatar Auto Selection

- Manuelle Einmal-Übernahme der empfohlenen Kombination in **Einstellungen → Diagnose → Avatar CPU-Profiling**.
- Nur aus lokal registrierten, verfügbaren GLTF-Modellen, die mindestens 80 Messwerte gesammelt haben.
- 1 oder 2 Avatare: solo bzw. sync; keine laufende Umschaltung und keine Änderung von Beatsynchronisation oder Choreografien.
- 3/4 Plätze im Advisor bleiben reine Empfehlungen; die Auswahlfunktion unterstützt derzeit maximal 2.
- Zurück zur vorherigen Kombination über die Avatar-Einstellungen. Hinweis: kein automatischer Rollback.
- CPU-Callback-Zeiten sind keine GPU- oder FPS-Garantie. Direkt auf dem Zielgerät messen.
