# Sonic Display V907 – Performance Profile Comparison Studio

## Geführter Ablauf

1. Den gewünschten Performance-Tier und die echten GLB-Avatare im bestehenden Bühnenmenü konfigurieren.
2. Einen wiederholbaren Songabschnitt abspielen und V826-Live-Telemetrie aktivieren.
3. Im V905-Benchmark **vor dem Start** manuell 2, 3 oder 4 sichtbare GLB-Avatare und den derzeitigen FX-Aufbau markieren. Das sind **Nutzerangaben**, keine verifizierten Messwerte.
4. Für jede Konfiguration drei unabhängige Benchmarks gleicher Länge/Szene/FPS-Zielsetzung starten.
5. V907 zeigt FPS-Median, durchschnittliche Framezeit, V826-P95-Fenstermittelwert, FX-Druck und vorsichtige paarweise Vergleiche.
6. Profilvergleiche anonym als JSON exportieren; keine privaten Song-IDs, Hardware-Spezifikationen oder Zeitstempel.

V907 ändert weder Avatarzahl noch Effekte automatisch. Unterschiedliche Songs, Szenen, Messdauer oder FPS-Ziele werden nicht verglichen. Profilvarianten sind nicht kausale Experimente; ein PC-Ergebnis sagt Raspberry-Pi-Performance nicht voraus.
