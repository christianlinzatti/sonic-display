# Sonic Display V473.5 – Concert-Camera TypeScript-Hotfix

## Ursache

Bei der Übergabe an `<Mode>` in `components/visualizer/VisualizerStage.tsx`
konnte `concertCameraCueV454` einen `SmartShowCueV446 | null` erhalten.
Der Prop-Vertrag akzeptiert aber `SmartShowCueV446 | undefined`.

## Änderung

Am Ende der bestehenden Kamera-Priorität wird ein fehlender Cue mit
`?? undefined` normalisiert. Kamera-Priorität, Genres, Choreografien, Avatare
und sonstige Einstellungen bleiben unverändert. Keine `as any`-Umgehung.

## Vermeidung weiterer Fehler

`npm run test:v4735` prüft den tatsächlichen JSX-Prop-Ausdruck mit dem
TypeScript-Typchecker im Strict-Modus. `build:preflight` startet diesen Test früh
und führt `npm run typecheck` vor dem zeitaufwendigen Next.js-Webpack-Build aus.

## Lokale Prüfung

```bash
npm run test:v4735
npx tsc --noEmit
npm run build
```

Für den vollen Next.js-Build werden alle Projekt-Abhängigkeiten benötigt.
