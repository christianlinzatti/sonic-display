# Sonic Display V389.6 — gesammelt behobene TypeScript-Probleme

Ausgangslage: `npx tsc --noEmit` auf Windows meldete 30 Fehler in 11 Dateien. Die Änderungen sind auf die vom Nutzer gemeldeten Fehler ausgerichtet:

- `CharacterMotionLibraryPanel`: nullable URL als optionalen Wert übergeben.
- `SonicDisplay`: im `!track`-Zweig keine Properties von `never` lesen.
- `danceQualityV307`: Schreibzugriff über `Record<string, number>` statt generischen Index.
- `RealLyricsStagePreviewV380`: `Object3D` bei externem Animations-Hook erlauben.
- `SpatialLyricsHandlesV381`: Pointer Capture nur auf sicher typisiertem Element; Nullfall berücksichtigen.
- `StageContentScreensV333`: Section-Wert auf Scheduler-Union begrenzen.
- `StageImageGalleryV338`: im `collage`-Zweig einen konstanten Slotindex verwenden.
- `StageScreenLayoutEditorV333`: Pointer-Handler für `HTMLElement` statt nur `HTMLDivElement`.
- `ThreeAvatar`: Timeline-Einstellung im Dancer aus Preferences lesen; nullable Genre-Props normalisieren.
- `VocalRigV367`: Kieferobjekt für Morph-Fallback explizit als `Object3D` typisieren.
- `VocalSyncInspectorV373`: optionale Quality/Articulation-Diagnostik explizit typisieren.

Prüfung in dieser Umgebung: `npm run check:syntax` erfolgreich (520 TS/TSX); V307, V333, V338, V373, V374, V380, V381, V389 Regressionstests erfolgreich. `npx tsc --noEmit` hier nicht aussagekräftig, da npm-Pakete einschließlich Next.js/React fehlen. Bitte auf dem Windows-Rechner nach Installation `npx tsc --noEmit && npm run build` ausführen.
