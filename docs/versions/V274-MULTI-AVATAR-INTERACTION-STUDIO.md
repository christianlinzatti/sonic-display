# Sonic Display V274 – Multi-Avatar Interaction Studio

Auf V273 aufbauende, standardmäßig deaktivierte Option im Multi-Avatar-Choreography-Panel.

- Musikalische Abschnitte aus geschätzten Audio-Energie-, Kick-, Bass- und Phrasenwerten
- Rollenwechsel zwischen Lead-Solo, Partner-Solo und Unisono; diagonal, breit und nebeneinander
- Hysterese gegen häufige Übergänge, unveränderte GLB-/Motion-Assets und bestehende IK- / Formationsabstände
- Bestehender V206-Taktdirector und manuelle Einstellung bleiben bei deaktivierter Option unverändert
- Keine exakte Verse/Drop-Erkennung: Live-Audiosignale sind heuristisch und bei Spotify ohne Audioinput nicht verlässlich

Aktivierung: Multi-Avatar Dance Director aktivieren und anschließend „V274: Intelligente musikalische Interaktionen“ einschalten.
Test: `npm run verify:offline`; Build: `npm install && npm run build`.
