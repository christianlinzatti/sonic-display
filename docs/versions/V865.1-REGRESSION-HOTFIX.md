# V865.1 – Regression-Hotfix für V844–V848

**Basis:** Sonic Display V865 (`package.json` bleibt `0.1.0-v865`). Dieser Hotfix korrigiert ausschließlich veraltete Testannahmen und enthält keine Änderung an Spotify-, Last.fm- oder Bühnenfunktionen.

## Ursache und Änderung

Die Regressionstests V844, V845, V846, V847 und V848 verlangten, dass `check:fast`, `check:release` und `build:preflight` **mit** der Testfolge `test:v850 → test:v849 → ...` beginnen. Seit V851–V865 stehen jedoch neuere Tests davor. Deshalb scheiterte V848 bei `startsWith(...)`, obwohl die alte Testfolge in korrekter Reihenfolge weiterhin enthalten war.

Die fünf Prüfungen verwenden nun `includes(...)` für **dieselbe vollständige, zusammenhängende Testfolge**. So werden das Vorhandensein und die Reihenfolge der alten Tests weiter geprüft, ohne den Anfang der aktualisierten Release-Kette vorzuschreiben.
