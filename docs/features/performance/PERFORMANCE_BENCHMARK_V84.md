# V84 – 3D-Performance-Benchmark

Unter Einstellungen → Diagnose den Benchmark starten. Der Avatar-Visualizer muss Render-Messwerte liefern.

Der Test schaltet High, Balanced, Low jeweils für 6,5 Sekunden (2 s Aufwärmen, 4,5 s messen). Danach wird der zuvor eingestellte Qualitätsmodus wiederhergestellt. Die angezeigten Messwerte stammen aus dem laufenden WebGL-Renderer.

Der Benchmark verändert **nicht automatisch** Avatar oder Lyrics-Stil; für Vergleiche jeweils die gewünschte Kombination einstellen und erneut messen. Ein Ergebnis hängt auch von Browser, Temperatur, Hintergrundlast und sichtbarer Szene ab. GPU-Auslastung (%) wird nicht gemessen.
