# V75 · Neon Pulse Lyrics

In **Settings → Anzeige → Lyrics · Animation** den Stil **Neon Pulse** wählen. Kinetic Typography, Cinematic Karaoke und Klassisch bleiben erhalten.

Neon Pulse zeigt maximal drei Zeilen, mit cyan/magenta Karaoke-Farbverlauf, gedämpften Nachbarzeilen und einer vom vorhandenen Beat-Signal gesteuerten Leuchtkraft. Die vorhandenen Regler für Intensität, Beat-Reaktion und Wort-Hervorhebung werden übernommen. Bei fehlenden Wort-Zeitstempeln wird die Position gleichmäßig pro Zeile geschätzt. `reducedMotion` bzw. `prefers-reduced-motion` unterbinden starke Effekte.

**Build-Hinweis:** Projektabhängigkeiten sind nicht im ZIP enthalten. `npm install` und `npm run build` lokal ausführen.
