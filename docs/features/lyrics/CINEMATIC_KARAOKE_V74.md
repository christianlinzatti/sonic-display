# Sonic Display V74 – Cinematic Karaoke

Settings → Anzeige → Lyrics · Animation → **Cinematic Karaoke**.

- Kinetic Typography bleibt standardmäßig aktiviert, sofern noch keine andere Auswahl gespeichert wurde.
- Cinematic: drei sichtbare Zeilen, große aktive Zeile, weich zurückgesetzte Nachbarzeilen, fließende Wort-Hervorhebung.
- Regler für Animationsintensität, Beat-Reaktion und Wort-Hervorhebung gelten für beide animierten Stile.
- Lyrics ohne Wort-Timestamps verwenden bei zeilensynchronem Material nur **geschätzte** Wort-Zeiten; ohne Zeilen-Zeitstempel keine Wort-Hervorhebung.
- `prefers-reduced-motion` beziehungsweise die App-Einstellung `reducedMotion` reduziert Animationen.

Bei Aktualisierung eigene Dateien unter `data/` und `public/avatars/` erhalten.
