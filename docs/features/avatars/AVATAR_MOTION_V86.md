# V86 – Avatar Motion Engine / Dance Studio

- **Hybrid** (Standard): eingebetteter GLB-Tanzclip mit gedämpfter musikalischer Rig-Modulation.
- **Choreography**: bevorzugt eingebetteten GLB-Tanzclip; minimale zusätzliche Bewegung.
- **Music Reactive**: bevorzugt Idle-Clip und stärkere audio-gesteuerte Bewegung.
- Crossfade für Clip-Wechsel, einstellbares Clip-Tempo, Arm- und Beinreaktion.
- Einstellungen unter **Settings → Avatar & Tanz → Dance Studio · Motion Engine V86**.
- Ohne kompatiblen Skelett-Rig sind Arm-/Bein-Modulationen eingeschränkt. Kein automatisches FBX-Retargeting und keine mitgelieferten Motion-Capture-Tanzclips.
- Bei ausgeschaltetem Mikrofon basieren die Musikreaktionen nur auf den verfügbaren Audio-Features.
- Einstellungen bleiben lokal im Browser und können jederzeit zurückgesetzt werden.
