# V91 – Foot IK im Dance Studio

Unter Settings → Avatar & Tanz → Dance Studio → Foot IK: aktivieren/deaktivieren, IK-Stärke (0–100 %), Bodenkontakt-Empfindlichkeit (0–100 %) und Fußfixierung (0–100 %). Standardwerte: aktiviert / 70 / 50 / 50.

Die Einstellungen werden im Browser über UiPreferences gespeichert und live an die Avatar-Bühne weitergegeben. Die Empfindlichkeit verändert Höhen- und Bewegungsschwellen für Bodenkontakt, die Fußfixierung begrenzt den Korrekturradius, und die IK-Stärke steuert den Einfluss der Korrektur.

Nur kompatible humanoide GLB-Rigs werden mit Two-Bone IK korrigiert. Andere GLB-Rigs behalten den vorhandenen V89-Fallback; der Procedural-Avatar besitzt keine Knochenkette. Dies ist kein vollständiger physikalischer IK-Solver.
