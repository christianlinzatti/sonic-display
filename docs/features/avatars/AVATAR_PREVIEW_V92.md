# V92 – Dance Studio Preview

- In Settings > Avatar & Tanz ist eine zweite Avatar-Vorschau für das Dance Studio verfügbar.
- Play/Pause, 0.25× Zeitlupe, 0.5×, 1×, 1.5×, 2× und Kamerasteuerung.
- Foot IK im Einzelbild ein-/ausschalten oder synchronisierten Links/Rechts-Vergleich starten.
- Links ohne IK, rechts mit IK; beide verwenden getrennte Skeleton-Kopien.
- Die Werte der Foot-IK-Regler aus den Einstellungen wirken direkt.
- Unterstützt enthaltene GLB-Clips und erkennbare humanoide Beinketten. Extern zugewiesene Animationsdateien werden in der Vorschau noch nicht berücksichtigt.
- Animationen mit unterschiedlichen Laufphasen können beim Umschalten geringfügig abweichen.
- Für den Procedural-Avatar steht keine Foot IK zur Verfügung.
