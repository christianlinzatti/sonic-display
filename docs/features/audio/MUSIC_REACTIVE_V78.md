# V78 – Music Reactive Lyrics

- Kick: kurzer Skalierungsimpuls (nur bei aktiver Mikrofonanalyse).
- Bass: dezenter Hintergrund-Glow.
- Starke Akzente: zusätzlicher Glow bei hohen Attack-/Bass-/Volume-Werten, keine verlässliche musikalische Drop-Erkennung.
- Unter **Settings → Anzeige → Lyrics · Animation → Music Reactive Lyrics** einzeln schaltbar und 0–100 % einstellbar.
- Vorhandene Styles, Smart Lyrics Sync, Offset und Lyrics Studio bleiben erhalten.
- Bei ausgeschaltetem Mikrofon oder reduzierter Bewegung sind die neuen Live-Effekte deaktiviert.

Prüfen: `npm install && npm run build`.
