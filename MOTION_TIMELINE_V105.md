# V105 – Motion Timeline Studio

Sequencer with multiple overlapping GLB clips, editable positions, durations, speed, crossfade curves and per-segment weight keyframes. Live playback in the GLTF avatar, loop support and JSON import/export. Local persistence via UiPreferences. Enable Timeline mode in Settings; disables V104 blend overlay while enabled. Timeline is only active during playback and does not export baked GLB. A procedural avatar does not have skeletal animation clips.

Build: `npm install && npm run typecheck && npm run build`.
