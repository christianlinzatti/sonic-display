# V865.7 – Three.js-Teststubs (V684–V688)

## Ursache
Die isolierten Test-TypeScript-Konfigurationen verwenden bewusst kleine `declare module "three"`-Stubs. Der Produktivcode `avatarRigController.ts` nutzt `Vector3`, `Object3D.getWorldPosition` und `Object3D.position`; diese echten Three.js-APIs fehlten in den alten Stubs V415 und V684.

## Änderungen
- `tests/stubs/v415-three-types.d.ts`: fehlende Vector3-/Object3D-Typen ergänzt.
- `tests/stubs/v684-three-types.d.ts`: dieselben Typen für V684/V685 ergänzt.
- Kein Produktivcode verändert; kein test skip, keine Typprüfung deaktiviert.

## Getestet
- `npm run test:v684:types` bis `test:v688:types`: erfolgreich.
- `npm run test:v686`: 74 Prüfungen erfolgreich.
- `npm run check:syntax`: erfolgreich (1261 Quellen).
- `npm run check:architecture`: erfolgreich (1001 Referenzen).
