# V473.3 – Next.js Client Directive Build Hotfix

## Ursache

Next.js/React Client Components require `"use client"` as the first top-level statement. In `components/visualizer/StageCameraDirectorV289.tsx` two imports preceded the directive. TypeScript's parsing step accepted this syntax, but Next.js SWC rejected it when compiling.

## Korrektur

- Moved `"use client"` to the top of `StageCameraDirectorV289.tsx`, keeping all imports and camera behavior unchanged.
- Enhanced `tests/check-source-syntax.cjs` so it rejects misplaced `"use client"` and `"use server"` directives across every TS/TSX source file.
- Added `npm run test:v4733` with synthetic valid and invalid directive fixtures.
- Runs directive/syntax checks *first* during `build:preflight`, before the time-consuming legacy regression suite.
- Retains V473.1 genre import fix and V473.2 duplicate import fix.

```powershell
npm run test:v4733
npm run check:syntax
npm run build
```
