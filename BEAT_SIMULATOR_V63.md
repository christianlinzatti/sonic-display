# V63 Beat simulator

Avatar settings include a visual beat simulator with Hardstyle (150), Techno (135), House (125), Half-time (85) presets and adjustable 60–200 BPM. It uses frame delta for a local simulation clock, triggers per-beat visual pulses and highlights every fourth kick. It does not generate audio, analyze Spotify, or modify global music playback. Existing V62 preview and OAuth fixes are retained.
