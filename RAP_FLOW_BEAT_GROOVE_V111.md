# V111 – Rap Flow & Beat Groove Engine

Adds configurable local, frame-by-frame beat accents on top of V110 without replacing its existing dance direction, timeline or choreography systems. Four controls (head, shoulder, bounce, snare) are persistent. Genre-aware: applies to Deutschrap, Hip-Hop, Trap and rap-tagged tracks. Works with normal audio features including optional microphone beat-phase lock.

Limitations: Kick and snare are approximate signal features, not isolated stems; no direct Spotify waveform or genuine syllable/rap-flow transcription. Auto mode is a heuristic. Reduced-motion and paused playback disable the new additive pose.

Validation: `npm install && npm run typecheck && npm run build`.
