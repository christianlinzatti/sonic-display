# Sonic Display V101 – Dynamic Stage

Bühnenstile: Classic, Neon Club, Festival, Minimal Studio. Einstellungen unter Avatar & Tanz. Die Beleuchtung reagiert auf Audioenergie; die Renderqualitätsregelung senkt die Lichtintensität. Fußboden und einfache Bühnengeometrie werden in der vorhandenen React-Three-Fiber-Szene gerendert. Keine zusätzlichen Pakete erforderlich.

Build: `npm install && npm run build`.
