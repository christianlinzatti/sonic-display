# V666.1 – Automatic Genre Dance (V666 Hotfix)

## Wunsch und Umsetzung
Der Genre-Tanz soll ohne manuelles Einschalten laufen. V666.1 verwendet bei frischen Installationen, fehlendem lokalen Schlüssel und unvollständig gespeicherten Alt-Daten standardmäßig `{enabled:true,strength:65,style:"auto"}`. Bei explizit gespeichertem `enabled:false` ist diese Entscheidung geschützt; ein explizit gewählter Stil bleibt erhalten. 

Die vorhandene Genre-Erkennung und V536-Motion-Auswahl bleiben die einzigen Quellen. Ohne erkennbare Tags bleiben zusätzliche Stilakzente aus; es wird nicht nach dem Geschmack des Benutzers auf Verdacht Deutschrap/Hardtekk unterstellt. Verse/Hook/Drop und Energie bestimmen die Intensität. V665-Stabilisierung, manuelle Clips und Bearbeitung, reduzierte Bewegung und Lippensynchronität bleiben unverändert priorisiert.

Die Funktion verwendet vorhandene GLB-Dateien und erzeugt keine neuen Clips oder echten Tanzbewegungen. Im UI bleibt eine optionale Deaktivierung und manuelle Genrewahl möglich, ist aber nicht mehr nötig. Die Konfiguration liegt weiterhin unter `sonic-genre-dance-performance-v666` und wird in portable Backups aufgenommen.

## Tests
`npm run test:v6661`, `npm run test:v666`, `npm run test:v666:types`, `npm run test:smoke:v6661`, `npm run build`. Vollständigen Produktionsbuild nur als bestanden melden, wenn npm-Abhängigkeiten installiert sind und `next build` wirklich erfolgreich läuft.

## Automatische Motion-Bibliothek
Auch `characterMotionLibrary.ts` und die Bibliotheksoberfläche verwenden bei fehlenden Einstellungen `automatic:true`. Ein gespeichertes `automatic:false` wird **nicht** überschrieben; bestehende Benutzerentscheidungen haben Vorrang. Die Software wählt ausschließlich aus tatsächlich installierten und passenden Animationen. Vorhandene gespeicherte `automatic:false`-Konfigurationen bleiben aus – bei solchen bestehenden Installationen muss die Automatik einmalig über den Bibliotheksschalter aktiviert werden.
