# Sonic Display V473.4 – TypeScript/Next.js Build-Hotfix

Basis: V473.3 mit allen bestehenden Musik-, Bühnen-, Avatar- und Rap-Funktionen.
Die Paketversion bleibt `0.1.0-v473`, weil die historischen Regressionen dieses Format voraussetzen.

## Fehlerursache und Änderungen

1. **Produktiv-TypeScript vs. Test-Stubs:** In `tests/v414-music-types.d.ts` wurde `declare module "@/types/music"` für isolierte Tests definiert. Da das Produktions-`tsconfig.json` zuvor alle `**/*.ts` umfasste, konnte diese Definition die echten TypeScript-Exports aus `types/music.ts` überdecken. Sie ist jetzt gezielt in `tsconfig.json` ausgeschlossen. Die historischen isolierten Test-`tsconfig`s referenzieren ihre Deklaration weiterhin explizit; ihre Tests bleiben ausführbar.
2. **Kamera-Imports:** In `StageCameraDirectorV289.tsx` wurden die bereits verwendeten V429-Funktionen korrekt aus `cinematicRapCameraV429.ts` importiert. In `ThreeAvatar.tsx` fehlen nicht länger die verwendeten V460-Feature-Funktionen.
3. **V456-Initialisierungsreihenfolge:** Die Berechnung von `attentionV456` steht jetzt vor `experienceCueV396` und `unifiedCueV402` – ohne Änderung des zugrunde liegenden Planungsschemas.
4. **V434 Qualitätseingabe:** Der Prüf-Eingabe wird das erforderliche `settings`-Objekt übergeben.
5. **Null-Prüfungen:** V420-Silbendokumente werden nur mit nachweislich vorhandenem Dokument dereferenziert; zusätzlich sind Schutzprüfungen für Auswahl, Kamera-/Vocal-Hinweise und Genre-Override ergänzt.
6. **Regression:** `tests/v4734-typescript-contract-regression.cjs` verhindert künftige Testtyp-Lecks in den Produktions-Typcheck und prüft die Integrationen. `npm run test:v4734`, `npm run verify:v4734`; im Build-Preflight wird der neue Test früh ausgeführt.

## Lokale Prüfung unter Windows

```
npm install
npx tsc --noEmit
npm run verify:v4734
npm run build
```

Beim Einspielen des Patches muss dein Arbeitsbaum dem bereitgestellten V473.3 entsprechen. Bei abweichenden lokalen Änderungen stattdessen Dateien aus dem V473.4-ZIP gezielt übernehmen.

## Teststatus

- `npm run verify:v4734`: erfolgreich (neuer Regressionstest + alte V467–V473-Ketten, V465/V466 TypeScript-Kernprüfungen, Syntax und Importintegrität).
- Zusätzlich `npm run build:preflight` begonnen: durch V451 erfolgreich; Gesamtlauf konnte hier nicht beendet werden.
- Produktives `npx tsc --noEmit` und `npm run build`: nicht ausführbar in der Prüfumgebung ohne installierte Projekt-Abhängigkeiten (`next`, `react`, `@react-three/fiber`, ...). Deshalb ist die Behebung der im Nutzer-Log enthaltenen Probleme anhand von Source/isolierten Tests abgesichert, aber der endgültige Windows-Build noch nicht bestätigt.
